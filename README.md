# Process Safety Culture Assessment

An offline browser tool to assess process safety culture on the **10 core principles** of CCPS (2018),
*Essential Practices for Creating, Strengthening, and Sustaining Process Safety Culture*.

**Open the tool:** https://chrispienaarthree.github.io/process-safety-culture/

- **Survey** – 50 short statements (5 per principle), English and Arabic, about 10–15 minutes, anonymous.
  Run it on one laptop or tablet, or send people the survey link for their own phones: each phone shows a
  response code that they send to the facilitator, who pastes the codes into the tool.
- **Facilitator review** – rate each principle 1–5 (Absent, Weak, Developing, Established, Strong) from interviews,
  documents and a site walk; tick red flags and note the evidence.
- **Results** – radar chart, score per principle and group, the management vs front-line gap, weakest statements,
  Don't know awareness gaps, red flags; an action plan; print to A4 / PDF; CSV and JSON export.
- Groups with fewer than 5 responses are hidden to protect anonymity. Nothing is sent anywhere: work stays in your
  browser and in the files you save.
- **Offline / USB stick:** download this repository as a ZIP, unzip it and open `Process Safety Culture Assessment.html` (or `index.html`).
- Quick guide: [`Process Safety Culture Assessment - Quick Guide.pdf`](Process%20Safety%20Culture%20Assessment%20-%20Quick%20Guide.pdf)

The survey statements are original wording mapped to the CCPS principles; they are not the CCPS assessment protocol
text. The Arabic translation is a draft until it has been reviewed by a native speaker. This is a screening and
discussion tool for training; it does not replace a formal culture assessment by competent people.
